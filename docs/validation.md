## Production hardening validation, 2026-10-29

Release build and self-contained win-x64 packaging completed with zero warnings/errors and **44 passed, zero failed, zero skipped** application tests on Windows 10.0.26200 / local NTFS, SDK 10.0.403. The earlier dated 32-case result above describes the prior implementation; recycling refusal and offscreen-only workflow coverage have since been replaced by the implementation and checks below.

- Real Windows Shell recycling of generated temporary duplicates, persisted receipt, refusal of an occupied restore destination, and successful journal restore preserving contents. An injected unavailable recycler retains recoverable staging without permanent deletion.
- Native MainWindow on a live STA dispatcher: scan, proposal, immutable review, declined and accepted confirmation, quarantine, busy state through history refresh, restore, export, profile save/load, malformed profile, stale history and cancellation. Choices use injected dialogs; actual common dialogs, packaged native startup, keyboard and screen-reader qualification remain outstanding.

Every connection enforces FULL synchronous and foreign keys. Exclusive application-data leases refuse concurrent owners and reopen after disposal.

These warm-cache in-process values are a smoke measurement, not cold-disk, isolated memory or million-file throughput evidence. The report is artifacts/performance/metadata-smoke.json.
